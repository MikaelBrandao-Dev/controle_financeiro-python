# Controle de Gastos - Terminal (Python)

Aplicação simples em Python via linha de comando para registrar entradas e saídas financeiras, calcular totais e saldo, e salvar os dados localmente em lancamentos.json.

## Funcionalidades
- Registrar entradas e saídas com validação de tipo e valor.
- Listar os lançamentos cadastrados.
- Exibir o resumo com total de entradas, total de saídas e saldo.
- Remover lançamentos pelo número da lista.
- Tratar entradas inválidas e arquivo inexistente ou corrompido.

## Como executar
```bash
python controle_financeiro.py
